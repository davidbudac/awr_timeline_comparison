About this reportlegend, method, sources

Reading the band

−20+2+3+8σlargemoderatenormalimproved

Shaded: the prior normal, mean ± 1σ dark and ± 2σ light. Ticks at ±2σ and ±3σ are the moderate and large thresholds. One scale for the whole page; past +8σ the dot pins to the edge and prints its z. A hollow dot past a tick moved, but not enough to matter.

Reading the 13 windows

prior windowCurrentsame normal rangeseverity on the Current barrelease or patch◆ plan changed✚ first seen▽ DOP downgrade

Every chart, card and Timeline row uses the same columns: oldest on the left, Current last and wider. Flags sit on the boundary between the two windows a release fell between. In the Timeline, hover a column to print its values and click a date to pin it.

Checked and normal

Every row is scored exactly like a finding: z = (current − mean) ÷ max(σ, 2% of mean) over the 12 prior windows. A hollow dot is normal; the text under the name is the normal range, mean ± 2σ, in the metric’s own unit.

Findings

Load profile (DBA_HIST_SYSSTAT, end − begin ÷ seconds), system metrics (DBA_HIST_SYSMETRIC_SUMMARY) and foreground wait classes (AAS), each against the same hour in the 12 prior valid windows. z = (current − mean) ÷ max(σ, 2% of mean); large beyond 3σ, moderate beyond 2σ, only when material and in the bad direction.

Mock-only: the 4 families group relatives beyond today’s twin/canonical links (table scans and logical reads under physical reads).

Load profile

DBA_HIST_SYSSTAT and DBA_HIST_SYS_TIME_MODEL, end − begin per window ÷ seconds. Scored like the findings.

System metrics

DBA_HIST_SYSMETRIC_SUMMARY averages; rates summed across instances, ratios averaged.

Foreground waits

DBA_HIST_SYSTEM_EVENT, foreground waits, idle excluded, end − begin per window. Scored with the wait-event policy: the floor is the event’s share of Current wait time.

Background waits

DBA_HIST_BG_EVENT_SUMMARY. A shift that moves every row by the same factor is demoted one step.

Top SQL

Top 10 in the Current window from DBA_HIST_SQLSTAT *_DELTA. The band compares this hour with the same statement in the prior windows where it made the top 10.

Mock-only: today’s report ranks statements without scoring them; this z is derived for the mock.

SQL Monitor

DBA_HIST_REPORTS where component_name = 'sqlmonitor', summaries only, scored on each statement’s maximum elapsed time per window.

Only completed, expensive-enough or parallel executions are persisted, so a missing statement did not necessarily run fast.

Segment I/O

DBA_HIST_SEG_STAT, top 10 segments per dimension.

File I/O

DBA_HIST_FILESTATXS and DBA_HIST_IOSTAT_FILETYPE.

Parameters

DBA_HIST_PARAMETER, value at each window’s end snapshot, lowest container wins.

Active sessions, whole span

DBA_HIST_ACTIVE_SESS_HISTORY, samples ÷ 360 per hour, 6-hour buckets smoothed with a 24-hour rolling mean. Dots: the unsmoothed 09:00 hour of each compared window. Application, System I/O, Concurrency, Other, Configuration and Scheduler are merged into grey.

Day profile

Each hour of the 24 h ending at 10:00 against the same hour on the 7 prior days, fixed daily cadence.

Utilization

Template-independent usage profile from DBA_HIST_SYSMETRIC_SUMMARY.

Compared windows

Begin and end snapshot per window; a window is skipped on a restart, a DBID change or a snapshot more than 15 min off its edge.

Timeline: Activity

DBA_HIST_ACTIVE_SESS_HISTORY, samples ÷ 360 in each compared hour, idle excluded.

Timeline: Headline and load

The six headline numbers plus the load counters behind the findings. Same scoring as the findings; the gutter is the band.

Timeline: Waits

DBA_HIST_SYSTEM_EVENT, foreground only, end − begin per window.

Timeline: Where the reads land

DBA_HIST_SEG_STAT and DBA_HIST_FILESTATXS, top 10 per window.

Timeline: SQL

DBA_HIST_SQLSTAT; SQL Monitor rows from DBA_HIST_REPORTS. Mock-only: the Top SQL band is derived for the mock.

Timeline: Configuration

DBA_HIST_PARAMETER, value at each window’s end snapshot.

Timeline

Each row is scaled within itself from zero; the Current column is the accented band. Release and patch flags sit on the boundary between the two windows they fell between, and their lines run through every lane. The right gutter is the same band and Δ as the Summary.

Day profile

Bar = this day, tick = prior-day mean, dot = flagged hour. Fixed daily cadence, independent of the weekly comparison. Fewer than 30 min of snapshot coverage in an hour leaves it empty.
