  • One shared column grid for the whole page: 13 windows, Current as a violet band that runs through every lane. Read down a column to see one window, across a row to see when something started.
  • Release and patch flags sit on the column boundary they fall between, and their lines run through every lane, so the config steps, the new SQL and the metric jumps line up under them.
  • One cell grammar everywhere: a grey mini column per window, the value printed only in Current (hover a column to print them all), the verdict in a right gutter. No heat tints, no pink rows.
  • The 3-month ASH spike field becomes 13 stacked one-hour columns. The full span moves to Full as a "week before each window" strip in the same columns.
  • "What changed" is five lines that jump to their rows; the finding isn't re-drawn as cards, a movers table and per-domain tables.
  • The day profile keeps its own 24-hour ruler, below the grid.
