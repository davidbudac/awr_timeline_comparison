Report redesign: three directions

Same data (the demo report, Current = Thu 10 Sep 09:00–10:00), same Oracle wait-class and wait-event colours. Only the presentation differs; All sections keeps every number.

A QuietB DocumentC Dashboard

Common to all three

  1. Spend colour on data only: wait classes / events, Current indigo, red & amber severity. Chrome is neutral zinc.
  2. One surface level: sections are flat cards with a 1 px border; no shadow, no card inside a card.
  3. Draw release markers once (on top), short and boxless everywhere else.
  4. Sentence-case labels, no uppercase tracking; Geist + Geist Mono embedded (OFL), tabular numbers in every column.
  5. Explanations move to a "How to read" popover; the Reading-the-charts guide stays the full reference.
  6. Severity reads as a badge or a 6 px dot, never as a dot + bar + coloured text at once.

What changes

  • Release markers drawn once, as a quiet track above the Activity chart; elsewhere a dashed line with a short label (R 4.2), no boxes.
  • Rail: no green dots on normal sections; a count with one small severity dot where something moved.
  • Verdict is plain type: no pills, a single stats line.
  • Help paragraph under the chart becomes a "How to read" button (popover).
  • Tables: hairlines only, severity as a leading dot instead of the red inset bar, CSV / MD behind one "···" menu.
  • Window bars print only the Current value; priors stay on hover (and in All sections).

Cost

Small. Mostly sql/_style.sql tokens and component rules + a handful of markup tweaks; demo twins follow.

Unchanged

Every number, every section and the All sections view; wait-class and wait-event colours; the indigo Current window; the band glyph’s meaning; offline rendering (fonts embedded, about 50 KB).

B

Document · Read it like an incident write-up

The shadcn docs layout: a plain left nav, a centred reading column (~720 px) and an "On this page" column on the right that also pins the comparison context. No cards at all: sections are headings, rule-based sentences, a chart and a small evidence table.
