## Why this matters

The report compares an Oracle database's Current window (e.g. one hour)
against the same hour in N prior periods. Two places print numbers a reader
has to decode:

1. **Durations as big numbers of seconds.** The plan-change card (section
   18) reads "**27.92 k** s elapsed, normal 5,785–7,552 s" — that is 7 h 45 m
   of elapsed time summed over the window, normally about 1 h 36 m–2 h 6 m.
   Its evidence rows say "max 8.016 s" and "CPU 4,467 s".
2. **Timeline wait-event rows without a usable unit.** In the Timeline view
   the Waits lane mixes wait-class rows from section 07 (in AAS, average
   active sessions: "8.285", label "wait class, AAS") with event rows from
   section 04 in *seconds waited per window* ("13.87 k", label only the wait
   class). `db file scattered read` at "13.87 k" is 3.85 AAS — the same
   number the Physical I/O finding card prints. AAS is the report's common
   currency for time (it adds up to DB time), so the event rows should use it.

After this plan, Summary-view durations are words of time, and every wait
row in the Timeline is AAS. Tables keep seconds with the unit in the column
header (precise, sortable, CSV/MD-exportable), and scoring is unchanged.

### Step 1: `fmt_dur` in PL/SQL and in the twin

Append to `sql/lib/fmt_num.plsql`, after `fmt_int` (end of file):

```sql
    -- fmt_dur(p_sec, p_short): a duration given in seconds, as words of
    -- time, for Summary-view text (the plan-change card, evidence rows).
    -- NOT for table cells (they keep seconds with the unit in the header:
    -- precise, sortable, exportable) and NOT for data-v / data-spark /
    -- AWR_DATA payloads (raw numbers).
    --   NULL          -> '&mdash;'          0           -> '0 s'
    --   under 1 s     -> '950 ms' (whole ms from 10 ms, '4.2 ms' below,
    --                    '<0.1 ms' when it rounds to zero)
    --   under 60 s    -> '8.0 s' (one decimal)
    --   under 1 h     -> '1 m 54 s' ('2 m' when the seconds round to 0)
    --   under 48 h    -> '7 h 45 m' ('7 h')
    --   otherwise     -> '3 d 4 h'  ('3 d')
    -- p_short = 'Y', for narrow window-bar labels: one unit only --
    -- '950 ms', '8.0 s', '38 m', '7.8 h', '31 h', '2.3 d'.
    -- A negative input keeps its sign.
    FUNCTION fmt_dur(p_sec NUMBER, p_short VARCHAR2 DEFAULT 'N') RETURN VARCHAR2 IS
        v_sign VARCHAR2(1);
        v_a    NUMBER;
        v_r    NUMBER;
        v_hi   NUMBER;
        v_lo   NUMBER;
    BEGIN
        IF p_sec IS NULL THEN RETURN '&mdash;'; END IF;
        IF p_sec = 0 THEN RETURN '0 s'; END IF;
        v_sign := CASE WHEN p_sec < 0 THEN '-' END;
        v_a    := ABS(p_sec);
        v_r    := v_a * 1000;                                -- milliseconds
        IF ROUND(v_r) < 1000 THEN
            IF v_r >= 9.95 THEN
                RETURN v_sign || TO_CHAR(ROUND(v_r)) || ' ms';
            ELSIF ROUND(v_r, 1) = 0 THEN
                RETURN v_sign || '<0.1 ms';
            END IF;
            RETURN v_sign || TO_CHAR(ROUND(v_r, 1), 'FM999990D0', 'NLS_NUMERIC_CHARACTERS=''.,''') || ' ms';
        END IF;
        IF ROUND(v_a, 1) < 60 THEN
            RETURN v_sign || TO_CHAR(ROUND(v_a, 1), 'FM999990D0', 'NLS_NUMERIC_CHARACTERS=''.,''') || ' s';
        END IF;
        IF p_short = 'Y' THEN
            IF ROUND(v_a / 60) < 60 THEN
                RETURN v_sign || TO_CHAR(ROUND(v_a / 60)) || ' m';
            END IF;
            v_r := v_a / 3600;
            IF ROUND(v_r, 1) < 10 THEN
                RETURN v_sign || TO_CHAR(ROUND(v_r, 1), 'FM999990D0', 'NLS_NUMERIC_CHARACTERS=''.,''') || ' h';
            ELSIF ROUND(v_r) < 48 THEN
                RETURN v_sign || TO_CHAR(ROUND(v_r)) || ' h';
            END IF;
            v_r := v_a / 86400;
            RETURN v_sign || CASE WHEN ROUND(v_r, 1) < 10
                                  THEN TO_CHAR(ROUND(v_r, 1), 'FM999990D0', 'NLS_NUMERIC_CHARACTERS=''.,''')
                                  ELSE TO_CHAR(ROUND(v_r)) END || ' d';
        END IF;
        v_r := ROUND(v_a);                                   -- whole seconds
        IF v_r < 3600 THEN
            v_hi := TRUNC(v_r / 60);
            v_lo := MOD(v_r, 60);
            RETURN v_sign || TO_CHAR(v_hi) || ' m' || CASE WHEN v_lo > 0 THEN ' ' || TO_CHAR(v_lo) || ' s' END;
        END IF;
        v_r := ROUND(v_a / 60);                              -- whole minutes
        IF v_r < 2880 THEN
            v_hi := TRUNC(v_r / 60);
            v_lo := MOD(v_r, 60);
            RETURN v_sign || TO_CHAR(v_hi) || ' h' || CASE WHEN v_lo > 0 THEN ' ' || TO_CHAR(v_lo) || ' m' END;
        END IF;
        v_r := ROUND(v_a / 3600);                            -- whole hours
        v_hi := TRUNC(v_r / 24);
        v_lo := MOD(v_r, 24);
        RETURN v_sign || TO_CHAR(v_hi) || ' d' || CASE WHEN v_lo > 0 THEN ' ' || TO_CHAR(v_lo) || ' h' END;
    END fmt_dur;
```

In `demo/awrdemo/helpers.py`, right after `fmt_int`'s twin (search

```python
def fmt_dur(p, short="N") -> str:
    """sql/lib/fmt_num.plsql fmt_dur: seconds as words of time."""
    if p is None:
        return "&mdash;"
    if p == 0:
        return "0 s"
    sign = "-" if p < 0 else ""
    a = abs(p)
    ms = a * 1000
    d1 = lambda x: to_char_fixed(ora_round(x, 1), 1)
    i0 = lambda x: str(int(ora_round(x, 0)))
    if ora_round(ms, 0) < 1000:
        if ms >= 9.95:
            return sign + i0(ms) + " ms"
        if ora_round(ms, 1) == 0:
            return sign + "<0.1 ms"
        return sign + d1(ms) + " ms"
    if ora_round(a, 1) < 60:
        return sign + d1(a) + " s"
    if short == "Y":
        if ora_round(a / 60, 0) < 60:
            return sign + i0(a / 60) + " m"
        h_ = a / 3600
        if ora_round(h_, 1) < 10:
            return sign + d1(h_) + " h"
        if ora_round(h_, 0) < 48:
            return sign + i0(h_) + " h"
        d_ = a / 86400
        return sign + (d1(d_) if ora_round(d_, 1) < 10 else i0(d_)) + " d"
    r = int(ora_round(a, 0))
    if r < 3600:
        return sign + str(r // 60) + " m" + ((" " + str(r % 60) + " s") if r % 60 else "")
    r = int(ora_round(a / 60, 0))
    if r < 2880:
        return sign + str(r // 60) + " h" + ((" " + str(r % 60) + " m") if r % 60 else "")
    r = int(ora_round(a / 3600, 0))
    return sign + str(r // 24) + " d" + ((" " + str(r % 24) + " h") if r % 24 else "")
```
